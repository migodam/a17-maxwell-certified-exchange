# Public scope

The archive is authorized for inspection and reanalysis of new A17 code and evidence. It is not a self-contained GPU replay bundle: 42 historical vendor kernels remain external with source hashes.

Eligible new executable Python and numeric NPZ files are original-byte copies. They are not passed through whole-source privacy replacement. Source identity, actual runtime receipts and explicit epochs distinguish executed code from newly authored plotting/test/report code.

JSON/JSONL and approved text metadata may have exact workspace/executable locator prefixes replaced by opaque markers. Numerical lexemes, scientific record fingerprints, rows, failure states and costs are preserved; each transformation has an exact pointer and original/public hash. This is narrower than saying all public source files or metadata bytes are unchanged.

Some derived CSV tables omit declared embedded JSON columns; row identities, surviving cells and omitted-cell hashes remain. Original primary raw JSON records remain. Sensitive config/test sources and private bulk-transfer archives are whole-file exclusions with reasons; they are not silently repaired.

PDFs are final author-reviewed documents. Existing baseline figures/evidence are identified as historical, not newly collected independent samples. Repository label “certified exchange” is a project name: strict output-error certification remains unestablished.

Public provenance audit documents present JSON pointers as reversible RFC 6901 token arrays, with original pointer hashes and whole-audit reversal fingerprints. This prevents a conservative filesystem detector from mistaking a logical JSON address for a private machine path. The standalone CPU algebra test is a new version without an interpreter header, AST-equivalent to its draft; it is not an altered historical Maxwell source. These two presentation decisions are recorded in audit/README.md and audit/PUBLIC_AUDIT_PROJECTION_RECEIPT.json.

See PUBLIC_SCOPE.json, INPUT_MANIFEST.json, PUBLIC_MANIFEST.json, TRANSFORMATIONS.json and EXCLUSIONS.json for exact public/private correspondence.
