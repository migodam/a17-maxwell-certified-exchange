# Maxwell 电流空间何时值得改变：材料用途与条件交换

## 结论先行

同一材料状态和相同实际电流维数下，从接收器导出的可靠基底出发，少量经过完整方向核验的条件交换，能够显著提高受测三维 Maxwell 问题中材料步对共同完整 GN 更新的保真度。十个完整的额外对象都改善，对象汇总的完整 GN 二次 gap 中位下降 **50.7%**；小型噪声检查保留了这一效应。三组完整受约束反演出现有限重建后果，其中两组复材料误差下降 **10.84% 和 7.16%**，接触对象基本中性。

论文应定位为 **A：Strong mechanism + conditional-design paper**。最强证据是固定表示维数下的材料步用途及其电磁解释。完整方向核验要支付额外物理作用，三组重建费用增加；最终图像、普遍推广和确定性安全证书各有自己的验收条件。

## 1. 研究为什么从电流出发

电磁逆散射根据外部散射场估计内部材料。材料不能直接到达接收器：它先在局部总场作用下激发感应电流，电流之间经过内部传播发生多重散射，最后辐射到测量通道。三维计算中电流自由度很多，电流子空间可以保留一个可求解的近似。

SOM 利用外部 Green 算子辨别可观测电流并处理材料/电流一致性。TSOM 进一步纳入内部传播；Fourier 与 FFT 组织使这类模型更易计算。这些方法已经包含重要物理。本文追问的是一个更具体的接口：当前材料、照明、残差与正则已给定时，换掉一个电流方向，究竟会让材料这一步变好还是变坏？

早期的双侧材料修正（paired repair）说明，改变电流模型确实会沿两组材料方向改变更新。然而等秩材料 Krylov 比它更强，完整支付后的 paired 路径更慢。宽域从零选择材料相关电流，也没有普遍胜过接收排序。由此形成现在更集中的问题：保留接收导出的稳定起点，只检验少量具体替换的材料用途。

## 2. 材料进入、反馈返回、实际用途是三个判断

设实材料方向为 $s$，物理正交展开为 $Q_T$。复介电材料的实部、虚部都在同一实坐标中。第 $p$ 次照明的材料激励 $B_ps$ 包含当前总场和 DDA 极化率导数 $a'(\chi)$。完整切向为

$$J_p=SL^{-1}B_p.$$

其中 $L$ 是当前内部电流方程，$S$ 把电流送到接收数据。全部照明共用材料变量；复数观测通过正确实化拉回材料法方程。高斯或体素（Gaussian/voxel）是不同的材料表示，不能用任意列缩放制造评分优势。

对保留电流基底 $V$，记 $R_0=V(V^*LV)^{-1}V^*$。新增电流 $C$ 不只直接辐射，还会激发保留电流响应：

$$\bar C=(I-R_0L)C=C+R_0XG_DC.$$

这是频域散射反馈的消元关系。它解释为什么 $SC$ 很小仍可能有显著 $S\bar C$：接收器还看到了保留电流携带的返回。DDA 的实际材料响应使用相应极化率与自作用约定，不能把极化率直接当作介电对比度。

指定增广的导数差为

$$D_C=Y_C\Gamma_C^{-1}N_C,$$

其中 $Y_C=S\bar C$ 是观测返回，$N_C=C^*(B-LR_0B)$ 是材料有效注入，$\Gamma_C=C^*L\bar C$ 保存全部耦合。保留块与 Schur 块稳定时，这是精确关系；共同核心奇异时改用稳定端点直接计算，不假装端点稳定能保证核心可逆。

## 3. 为什么不能把“信息变多”当成“更新更好”

冻结正则材料二次目标为

$$\Phi_F(s)=\tfrac12\|r+J_Fs\|^2+\ell^Ts+\tfrac12s^T\Lambda s.$$

材料步既依赖曲率 $J^TJ$，也依赖当前残差的拉回 $J^Tr+\ell$。新旧电流模型给出的实际步差满足

$$d=s_n-s_o=-H_n^{-1}(\Delta h+\Delta\mathsf I\,s_o).$$

改变近似模型会产生干涉交叉项，两个正定 GN 矩阵的增量仍可不定。这与增加独立测量不同。对一个真实 Maxwell 替换，信息体积增加 6.3127、有效维数增加 1.8613、曲率保真标量还略改善，但完整收益为负。原因必须同时看残差偏置和曲率作用，不能把负收益单独归因于某一项。

双侧支撑定理说明精确步差位于

$$s_C-s_0\in H_0^{-1}\operatorname{Range}[J_0^*Y_C,N_C^*].$$

它描述改变发生在哪里，不自动给出最小维数、廉价选择器或收益保证。一般 least-squares 模型即使没有散射反馈也有双侧耦合；Maxwell 特定内容由真实材料激励、保留反馈和复接收返回承担。

## 4. 方法怎样执行

每次从接收奇异方向组成的 $k=4,8,16$ 列复电流基底开始；全部照明共享该基底。保持的是实际电流秩，原 receiver 列允许被替换。

1. 固定的 154 原子字典提供按六类来源轮询的 12 方向短候选池（family-balanced incoming pool）；每类按固定顺序取两个尚未选中的方向。来源与数量在补充材料逐项说明。
2. 独立的 64 列 richer reduced anchor 对具体一出一入端点生成的实际材料位移排序。
3. 每轮最多两个 finalist 接受完整方向切向作用。
4. 正收益超过在线数值意义阈值才接受；否则保留当前空间。
5. 接受以后重新计算条件耦合与邻域；最多接受三次。

对当前材料步 $x$ 和候选实际位移 $d$，完整收益是

$$Q=-g_F(x)^Td-\tfrac12d^TH_Fd.$$

缓存 $u=r+J_Fx$，计算 $z=J_Fd$，就得到

$$Q=-\operatorname{Re}\langle u,z\rangle-(\ell+\Lambda x)^Td-\tfrac12(\|z\|^2+d^T\Lambda d).$$

这不需要完整最优步或新增完整伴随，但 $Jx$、每个被检查和被拒绝的 $Jd$ 都收费。同 $k$ 比较的是表示用途，不是同信息或同计算费用。

## 5. 部署阈值修正没有改变原科学结果

原接受阈值曾部分依赖离线完整 reference 的 evaluation floor。现在 controller 只使用在线 gain 项尺度、FP64 和预先固定常数；不读取真值、完整最优步或风险底噪。分析固定于验证之前，没有根据新对象收益调参。

原 36 单元进行了真实物理回放：75 个接受动作、顺序、每轮步和输出、终态空间保持一致，风险差为零。该容差判断浮点意义，不是合法 Maxwell output-error radius。论文统一使用 verified exchange / high-fidelity numerical verification；严格 certificate 只保留有条件的理论形式。

## 6. 规则锁定以后，材料步收益怎样分布

原四个对象的 36 单元中 35 改善、1 相同；对象内先求和再计算风险比，中位 0.347848，即 gap 下降 65.2%。这组数据属于开发证据。

其余十一项兼容对象在新结果之前固定进入计划，每对象早/中/晚三状态及三预算。十个对象完整提供九单元且全部改善；中位比 0.492818，四分位区间 [0.3314,0.5588]，10,000 次对象 bootstrap 的中位数 95% 区间 [0.3133,0.5647]。

另一个非对称 voxel 对象的早/中期六单元改善。晚期第一个预算的 receiver endpoint 未通过预设法方程残差检查，后续两个预算不运行。预定 99 单元中 96 有审计结果：95 改善、1 相同、0 恶化；1 FAIL 与2 NOT_RUN仍在分母中。

绝对 receiver gap 为 $2.74\times10^{-7}$ 到 $3.09\times10^{-3}$，最小分母仍超过 evaluation floor $6.31\times10^9$ 倍；完整 reference 最大真残差为 $9.55\times10^{-12}$。收益不是小分母的显示效应。

额外对象有历史研究暴露，不能确认整个集合严格新盲测。准确名称是 locked-rule additional-object validation。对象是汇总单位，不能把状态、预算或噪声 realization 当独立物体；bootstrap 是固定资产集合的描述，不是任意物体分布保证。

## 7. 噪声检查支持什么

几何与材料表示预选的四对象固定中期状态，1%/3%复噪声各三份 realization、三个 $k$，共72单元。每份残差都有自己的完整 reference，在线规则保持不变。

71 单元改善、1 no-op、0 恶化。对象中位风险比为 0.330653 和 0.402576。空间的部分方向明显随残差改变，因此效果来自条件用途，而不是不随数据变化的普遍模式表。

408 个 finalist 被核验，其中98个低于数值接受阈值；172次交换接受。$Jd$ 用2448个真实 current RHS，包括拒绝动作；连 $Jx$ 共2880。四对象、两个水平和固定状态只支持这一有限噪声范围。

## 8. 真实重建改善多少，代价多少

四代表对象使用相同初始化、材料参数化、prior、LM schedule、可行域、Armijo line search 和18更新上限，仅 tangent-current policy 不同。三组完整配对得到：

|对象 / 材料表示|复材料相对误差 receiver → exchange|相对下降|留出数据误差 receiver → exchange|完整 child-wall 比|
|---|---:|---:|---:|---:|
|平滑 / voxel|0.3027 → 0.2699|10.84%|0.006637 → 0.002836|2.68|
|近接触 / Gaussian|0.6722 → 0.6707|0.22%|0.010521 → 0.007080|1.74|
|壳体 / Gaussian|0.6096 → 0.5660|7.16%|0.014190 → 0.012179|1.46|

接触实部略差，峰值与界面仍不清晰，数据拟合改善不自动解决材料辨识。第四条 exchange 轨迹保留17次已接受更新；第18次更新前为开始当次交换构建的 receiver endpoint 失败。独立 receiver-only 基线未运行。不能把这个内部阶段失败写成基线已失败，也不能把安全前缀当完成对照。

裸单位步不作为重建结论。共同 constraints、feasibility projection、non-descent fallback 与 full nonlinear Armijo 把局部材料方向变成真正执行步。这些操作之后，冻结 quadratic 的正收益不再是自动的 nonlinear/truth 保证，需要分别测量。

## 9. 三个物理边界值得保留

直接暗电流在受控三维网格上的 isolated receiver output 低于 $1.7\times10^{-16}$，反馈后达到0.0672–0.0888，并改变材料导数3.56–5.22%。这个见证证明直接输出可能漏掉材料通路，不因果归因每次部署收益。

两个单独不利的新增方向可以联合有利：$Q_A<0,Q_B<0,Q_{AB}>0$。540个预定pair中有5个此类见证。它说明 conditional relevance 可非加性；不是普遍概率、非次模 theorem 或同秩交换陷阱。

共同候选的受控2×2诊断中，强制top-one并关闭no-op时，actual-d线性评分29/36次选到负收益，完整二次评价仅1/36。有限位移的曲率代价确实改变排序；这个计数不是部署失败率。旧finite/first-order比值还混合了位移与终端搜索差异，不能归因于单独二次项。

## 10. 新结果没有替换历史负结果

原双侧修正对指定 direct enlargement 的72/72平滑、36/36尖锐比较更好；等秩材料Krylov又在全部比较中更强。旧paid paired耗时1.416倍、RHS66→342保留。宽域from-scratch材料选择的对象中位receiver风险比1.0947仍是负结果；现在的receiver-centered conditional exchange回答更窄的问题。

尖锐目标的材料辨识限制、高对比球21.40%粗离散偏差和原闭包小尺度失败均保留。独立moderate-sphere Mie的场与均匀材料导数核验不能扩展成全部voxel方向或所有非径向对象的认证。

## 11. 文献与正式投稿的边界

SOM/TSOM 已包含接收和内部传播；goal-oriented、derivative-preserving、primal/dual ROM 以及adaptive高精度验收都有先例。全文比较已锁定教材、综述、MR-FFT作者校样、interpolatory inverse-ROM与adaptive inverse-ROM。部分原生论文全文仍OPEN，不能据缺口声称历史首创。

独立TAP、电磁子空间及numerical inverse-ROM模拟审阅没有发现新的致命核心代数错误，但都要求清楚区分Maxwell设计接口与成熟工具、同表示秩与同费用、局部保真与最终图像。科学定位与投稿准备分开：证据支持A定位；形式作者确认、最近邻全文定位和最终交付检查是另一个门槛。

## 12. 五类 claim

**proved：**固定模型的材料切向、Schur导数差、双侧步差包含、曲率增量可不定、实际位移的完整二次收益。采用已有代数工具，不自动作原创 theorem。

**numerically supported：**原四对象、在线阈值真实回放、物理机制见证、有限三对nonlinear后果、方向核验的实际费用。

**holdout validated：**冻结规则在额外历史对象上的GN保真改善和规定四对象的有限噪声效应；不等于严格新盲测。

**not established：**全局或普遍电流ranking、strict blind generalization、deterministic certificate、原生TSOM优越性、equal-cost superiority、faster imaging及普遍truth改善。

**failed：**宽域from-scratch selection的普遍优势、paired对等秩Krylov的优势/加速、第四nonlinear完整对照。

## 13. 从机制到可使用的设计原则

判断一个电流替换时，先问材料能否激发它，再问内部响应能否返回接收端，最后评价它实际生成的有限材料位移。前两问解释通路，第三问决定当前用途。本文的明确结果是：在规定范围内，这个有费用、有限次的条件设计显著改善了固定电流表示的材料步。候选取得、搜索覆盖、完整费用和最终材料估计分别保留边界，这让设计原则可以被检验、复现和继续改进。

## 14. 完整费用与当前成像后果

全部历史尝试、失败、核验及离线字典诊断合计 **19,962.060 秒（5.545 小时）**，在已授权 12 小时上限内闭合。61 个 closure attempt 与两次被拒 preflight 全部保留；嵌套阶段没有重复相加。三对独立重建总 child-wall 比为 **2.68、1.74、1.46**，均更慢。主结论是用额外物理核验购买局部材料步保真度。详见 A17_FINAL_COST_AUDIT.md 与逐 attempt 公共派生表。

公开 saved-array 工具重算六个完整终点的 36 项指标及三对的 18 项比值，与审计统计完全一致。125 条保存更新曲线也一致。第四对象的失败前缀没有保存 measured/held 场，严格全指标模式因此失败；支持已有量的模式保留这些量为 null，不把安全前缀叫作完成重建。

## 15. 候选覆盖的最终解释

完整字典的初次1-swap诊断已关闭：32状态、96/99单元完整，前置端点失败的3单元保留未运行。十个完整额外对象中，全字典anchor top-one保留97.30–99.99%的正收益机会，中位99.54%；固定12移入方向短池只覆盖49.12–95.31%，中位72.95%。因此当前最清楚的实际瓶颈是把有用方向送进候选池，而不只是让排序更复杂。

这些比例度量的是共同receiver起点的一次机会，不是整个部署路径或最终成像改善。最多三步的全字典完整收益greedy在90/96单元有更低终态gap，线上路径在5单元更好，1单元在评价floor内相同。局部teacher不是全球oracle；两条路径差距同时含覆盖、排序和后续邻域交互。详见A17_CANDIDATE_COVERAGE_FINAL.md和OWNER_COVERAGE_STATISTICS_FINAL.json。

统一实验账本保留314个计划行：36replay、99primary、72noise、8nonlinear、99offline coverage。这个总数是可追溯分母，不是314个独立场景；相关状态、预算与噪声实现仍按对象聚合。
