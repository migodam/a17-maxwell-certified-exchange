# Public evidence scope

This additive study contains six 3D geometries, six fixed primary policies, and two fixed posthoc gradient controls. The frozen A17 manuscripts and historical result folders are unchanged.

- `data/` contains saved inputs, compact final material arrays, original final/trajectory records, collected CSVs, global costs and selected original failure records.
- `figures/` contains plots of actual saved materials. Synthetic truth is explicitly labelled. Thresholded support is accompanied by raw real/imaginary slices.
- `source/` preserves the original project-relative layout of the explicitly exported implementation/dependency files. Executable source is copied without text-redaction transformations. Imports, logging and endpoint adapters are documented; this is not a claim that every helper is verbatim historical-paper source.
- The release raw archive additionally contains checkpoints, complete exchange traces, failed-prefix records and cost histories. Private SSH settings/keys, environment directories, unrelated studies and private transport diagnostics are excluded.

This is an evidence/reanalysis and source package. Packaging did not run new physics or regression tests. Historical CPU/CUDA execution was not repeated in the public copy, and full original-paper GPU replay is not certified by this export. REPRODUCTION.md describes the available entry points and limits.

All38 trajectories reached the18-update cap; this is not convergence. A17 beats receiver in3/6 primary material-error values; its median ratio to receiver is1.0328. A native crash and an unexplained logging-namespace exception are preserved; their root causes/numerical impact are not resolved by successful continuation. Do not present these additional GPU examples as an independent replacement for the frozen paper evidence.
